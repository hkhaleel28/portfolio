# Portfolio

A personal portfolio site, and a hands-on learning project for DevOps.

- **Frontend:** React + Vite
- **Backend:** Python (FastAPI)
- **DevOps track:** Docker, GitHub Actions CI/CD, Azure, Terraform, Kubernetes

The plan lives in [docs/ROADMAP.md](docs/ROADMAP.md). This README grows as each phase lands.

## Status

Phase 0 (workstation and tooling setup) is complete. Application code starts in Phase 1.
